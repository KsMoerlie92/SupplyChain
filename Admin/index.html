Huidige status

Inspection Level — projectregels

Bepaalt automatisch kolom AA (Inspection Level) in de Itemlijst Validator, op basis van component (Mark/Label) en/of leverancier, per project. Wordt eenmalig bij projectstart ingesteld en kan gaandeweg bijgesteld worden — bijvoorbeeld als de prestaties van een leverancier verslechteren. Vult alleen lege AA-velden aan; een handmatig ingevulde waarde wordt nooit overschreven.

Risicoprofiel-Excel: verwacht kolom A (code, bv. 1046), C (omschrijving) en O (Risicoprofiel, kleur bepaalt het niveau — rood → Fysiek controleren, oranje → Foto's en Steekproef, groen → Geen Controle). Vraagt om het Sub Project ID vóór het importeren.

Na wijzigen wordt inspection-rules.json gedownload. Commit dat bestand naar shared/ (net als expediting-data.json) en deploy — daarna gebruikt de Itemlijst Validator deze regels automatisch.
